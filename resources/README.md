# PCM resources

`icon.png` is the 64 × 64 px KiCad Plugin and Content Manager icon: a crop of the "S" from
`assets/StripForge-icon-1024x1024.png`. It goes in the package archive as `resources/icon.png`
(next to `metadata.json`), and as `icon.png` beside `metadata.json` when the package is submitted
to the KiCad metadata repository. The `metadata.json` schema itself has no icon field.
